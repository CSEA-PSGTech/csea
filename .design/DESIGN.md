# Finder Component Design

## Goal

Create a decorative Finder-inspired member browser for the CSEA website.

This is NOT a real filesystem.

The user navigates:

CSEA
→ Faculty
→ Technical Team
→ Design Team
→ Members
→ Member details

## Visual Direction

The component should feel like macOS Finder.

Reference:
- references/finder-main.png
- references/finder-gallery.png
- references/existing-window.png

## Window

- Rounded macOS-style window
- Traffic light controls
- Dark translucent title bar
- Subtle border
- Soft shadow
- No excessive gradients
- No generic dashboard appearance

## Sidebar

- macOS Finder-like sidebar
- Muted labels
- Compact navigation items
- Selected item has subtle rounded highlight
- Icons should use Lucide icons

## Main Area

- Spacious
- Folder grid
- Large folder icons
- Member photos displayed as thumbnails
- Name underneath
- Subtle hover state

## Typography

- System font stack
- Small secondary text
- Clear hierarchy
- Avoid oversized headings

## Animation

- 150–250ms transitions
- Folder navigation should feel smooth
- Avoid excessive animations

## Important

Do not redesign the existing website.

Do not introduce a new visual language.

Do not modify unrelated components.
